# FilmPick 使用说明书

适用于 FilmPick 1.7.1 · Windows x64

FilmPick 用于快速翻看本地照片和视频、给素材打星和标记，以及把已选和已排除的素材连同附属文件复制归档。

## 第一次选片

1. 完整解压 Windows x64 便携包，运行解压目录里的 `FilmPick.exe`。播放、RAW 预览和元数据组件都随包附带，请保留解压后的文件结构。
2. 点「打开素材文件夹」，进入素材目录并点击「使用当前文件夹」。也可以选中一个媒体文件来打开它所在的目录。素材位于多级目录时，勾选「包含子文件夹」。
3. 在左侧选「照片」或「视频」。如果当前模式没有素材而另一种模式有，预览区会提示「切换到照片」或「切换到视频」。
4. 用 `↑` 和 `↓` 翻片，按 `3` 标记已选、`2` 标记排除、`1` 清除旗标。想标记完立刻看下一条，可以勾选「标记后自动跳到下一条」。
5. 选完点「预览归档」，核对主片、附属文件和目标路径，再点「确认复制」。两类副本会进入素材目录同级的 `原目录名_已选` 和 `原目录名_已排除`。

素材目录须位于本机 NTFS 固定磁盘。存储卡或网络盘里的素材可以先复制到本机工作目录。扫描会跳过符号链接、目录联接点等重解析点。

## 浏览、筛选与排序

- 点「文字列表」或「缩略图」切换左栏视图。照片和视频各自记住上次选择。缩略图默认一列，拉宽左栏可自动分列，鼠标悬停在名称上可看完整文件名。
- 搜索框按文件名查找，也匹配配对的 RAW 文件名。点击框内的 × 可以清空搜索词。
- 「筛选」支持拍摄日期区间、日期未知、多个星级和多种选片标记。同组条件满足任意一项即可，不同组的筛选要同时满足。打开素材文件夹时会清空筛选。
- 排序字段包括名称、拍摄日期、星级和选片标记。用箭头切换正序和倒序。照片和视频各自保存排序方式。
- 拖动分隔线，可以调整左栏和 LUT 库的宽度以及底部操作区的高度。从「设置」可以恢复初始布局或修改快捷键。

## 照片和 RAW 预览

| 类型 | 识别的扩展名 |
| --- | --- |
| 常规照片 | JPG、JPEG、PNG |
| RAW | NEF、NRW、CR2、CR3、ARW、RAF、DNG |

同目录里唯一匹配的同名 RAW 和 JPG 会合为队列中的一条，优先显示 JPG。归档时两份都会复制。

单独的 RAW 会先尝试显示内嵌预览。如果内嵌图的像素不足以填充当前显示区域，FilmPick 会在后台解码 RAW，完成后换成高分辨率预览。信息栏会显示预览来源和分辨率。放大窗口或移动到不同缩放比例的屏幕时，程序会重新评估内嵌图是否够大。

Nikon HE／HE★ 当前使用内嵌图预览。RAW 缩略图使用配对 JPG 或 RAW 内嵌图。缩略图缺失时，可以点击该条查看中央预览，也可以正常标记和归档。解码失败且有内嵌图时，中央预览会保留该图，悬停在信息栏可查看失败原因。HEIC 当前尚未纳入照片队列。

## 视频和拍摄参数

- 支持 MP4、MOV，主要适用于 H.264 和 HEVC。拖动进度条定位，或用左右键逐帧检查。点击倍速按钮在 1× 和预设倍速间切换，旁边的菜单可设定预设档，默认 3×。也可以长按左右键临时快退或快进。
- 有唯一匹配的 LRF 时，按 `V` 或点「切代理」在原片和代理之间切换。视频缩略图优先使用匹配的 LRF。
- 点「参数」或按 `Tab` 显示或隐藏画面左上角的拍摄参数。可读到的信息包括日期、曝光和焦段。视频额外显示原片的分辨率、帧率、编码、色度采样、位深和色彩，即使正在播放代理也可以查看。
- 位深从 H.264、HEVC、AV1 或 VP9 原片的编码配置读取，显示为 `8 bit`、`10 bit` 或 `12 bit` 等。无法从原片确认时显示「位深未知」。
- 可识别的拍摄色彩包含 D-Log、D-Log M、S-Log3、Rec.709、HLG 和 PQ。随片的 DJI SRT 和 Sony XML 可提供拍摄模式。只有视频轨道信号标签时会注明来源，例如「Rec.709（标记）」。色彩字段描述原片，所选预览 LUT 的名称显示在 LUT 按钮上。
- 有可读的 DJI SRT 时，曝光和飞行参数会按当前播放时间更新。能读取的字段随素材而异，包括 ISO、快门、光圈、相对高度、绝对高度、速度和坐标。
- 焦段同时显示真实值和可确认的 35mm 等效值，例如「28 mm（等效 42 mm）」。全画幅素材只显示真实焦段。DJI SRT 只提供等效字段时显示「等效 168 mm」一类的值。

识别到的 DJI D-Log 和 D-Log M 原片会优先使用兼容硬解。如果开头几帧出现花屏，可点击解码状态旁的「软解重试」，从当前播放位置重新打开。

## 星级和选片旗标

星级用于评分。点预览上方的星星或按 `Ctrl+1` 至 `Ctrl+5`，用 `Ctrl+0` 清除星级。旗标用于标记已选和已排除，也是决定哪些素材参与归档的依据。打开「筛选」勾选星级或旗标，只会改变当前显示的队列。

### 修改分级会写到哪里

| 素材 | 修改后的保存位置 | 新归档副本的分级 |
| --- | --- | --- |
| JPG、JPEG、PNG、DNG | 后台写入源文件的标准元数据，提交前校验图像数据 | 复制完成后携带最新已写入的分级 |
| NEF、ARW 等专有 RAW | 后台写入旁边的同名 `.xmp`，RAW 本体保持原样 | RAW 和关联的 XMP 一起复制，支持 XMP 的软件可读取分级 |
| 唯一配对的 RAW＋JPG | 同一条修改分别写入两份素材对应的元数据 | 两份主片和关联的 XMP 随组归档 |
| 视频 | 保存在本机 FilmPick 针对该素材目录的记录里 | 打开新归档目录时，视频副本的 FilmPick 星级和旗标从空白开始 |

照片改星或改旗标后，界面即时更新，后台再写入并回读校验。底部出现「分级待写」时可点开看原因。解除文件占用后点击「重试」。归档前会核对这些记录，并在清单中列出需要暂缓复制的组。

JPG 星级可在资源管理器的「分级」列查看。外部应用能否显示旗标取决于它对元数据的支持。使用 Lightroom Classic 时，已有目录可通过「元数据 → 从文件读取元数据」刷新。旧版仅保存在 FilmPick 的照片星级或旗标，在重新修改对应字段后才会写入标准元数据。

## LUT 预览与管理

1. 点右上角「LUT 库」。可一次导入多个 2–65 阶的 3D `.cube`，第一项有效 LUT 会自动应用。初次试用时，可用「临时试用」，选定后点「保存到库」。
2. 点库内卡片更换预览 LUT。点预览区上方的 LUT 按钮或按 `L` 可以开关效果，该按钮同时显示当前 LUT 的名称。中央预览和队列缩略图会随之更新。
3. 用「编辑」修改库内名称和标签，可在库中搜索、仅看收藏或按多个标签筛选。卡片上的固定样图用于辨认 LUT 的色调。移除一项只会移除库内副本。
4. 用「导出 ZIP」备份完整 LUT 库、标签和收藏，用「合并 ZIP」导入到另一台电脑。内容相同的 LUT 保留本机设置，同名而内容不同的 LUT 会各自保留。导出时请选择尚未存在的 ZIP 路径。

照片、原视频和 LRF 共用当前所选 LUT，请按素材色彩选择合适的转换。LUT 效果只用于预览。切到另一个素材目录或重启后，FilmPick 会关闭 LUT 效果。导入项独立保存在 `%LOCALAPPDATA%\FilmPick\lut-library`，原始 `.cube` 文件可以移动。LUT 库备份涵盖已保存的 LUT 和库内设置。

## 附属文件和复制归档

1. 选中素材并点「附属文件」，查看会随组复制的文件。FilmPick 会自动关联能唯一匹配的 LRF、SRT、XML、XMP 等附属文件。在这里还可以为当前扫描范围内未归组的文件手动指定所属素材。跨子文件夹关联时，请勾选「包含子文件夹」。
2. 点「预览归档」检查清单。清单按当前扫描范围汇总两种模式的已选及已排除素材，包括被筛选隐藏的条目。确认哪些素材已经标记和会复制到哪里，再点击「确认复制」。
3. 在源目录同级查看 `原目录名_已选` 和 `原目录名_已排除`。主片与已关联的附属文件按原名和相对目录复制。举例来说，`活动\机位A\片段.MP4` 标记已选后会复制到 `活动_已选\机位A\片段.MP4`。

归档是复制操作，源素材保留在原处。如果目标组已有完全相同的文件，程序复用它们并补齐缺项。如果目标组存在内容不同的同名文件，整组会跳过，既有副本保留。要更新旧副本的分级，可先核对归档报告，再将发生冲突的旧副本移到其他目录后重新归档。

复制中断后，重新打开原素材目录并点「恢复未完成的归档」。如果报告指出某个目标侧暂存文件无法验证，先检查该文件，再按报告提示处理并重试。布局、快捷键、视频分级、附属文件手动关联和归档恢复记录保存在本机 `%LOCALAPPDATA%\FilmPick`。

## 默认快捷键

| 按键 | 操作 |
| --- | --- |
| `↑` / `↓` | 上一条 / 下一条 |
| `1` / `2` / `3` | 清除旗标 / 排除 / 选中 |
| `Ctrl+Z` | 按倒序撤销本次打开目录后修改的旗标 |
| `Ctrl+1` 至 `Ctrl+5` / `Ctrl+0` | 设置星级 / 清除星级 |
| `Tab` | 显示或隐藏拍摄参数 |
| `L` | 开关当前 LUT |
| `空格` / `M` | 播放或暂停 / 切换静音 |
| `←` / `→` 短按 | 暂停并后退 / 前进一帧 |
| `←` / `→` 长按 | 临时快退 / 快进，松开恢复 |
| `Shift+←` / `Shift+→` | 后退 / 前进 5 秒 |
| `V` | 在原片和唯一匹配的 LRF 之间切换 |

数字键支持主键区和小键盘。通过「设置 → 快捷键」可以自定义按键或恢复默认快捷键。

## 从源码构建

安装 Windows x64 的 .NET 10 SDK，从 FilmPick 源码仓库根目录运行以下 PowerShell 命令。

```powershell
.\build.ps1 -Test -Package
```

脚本会构建项目、运行测试、下载并校验播放和元数据等组件，然后在仓库上一级的 `artifacts` 目录生成 `FilmPick-1.7.1-win-x64.7z`。如果 SDK 未加入 PATH，可以通过 `-Dotnet` 指定 `dotnet.exe`。

要单独运行测试，可以使用 NTFS 上的一个临时目录。以下命令会在系统临时目录下创建本次测试用的数据。

```powershell
dotnet run --project .\FilmPick.Tests -c Release -- $env:TEMP
```

如果便携包随附 `benchmark.json`，它记录的是单机实测的预览和切片用时。相关依赖版本及许可信息见 [第三方组件说明](THIRD-PARTY.md)。
