# FilmPick

FilmPick 1.7.2 是面向 Windows x64 的本地照片和视频选片工具。打开或拖入素材后，可以用文字列表或缩略图快速浏览，用键盘标记和打星，再把已选、已排除的素材连同附属文件复制到相邻目录。

- [下载单文件 EXE 或便携 7z](https://github.com/cz15909681360-create/FilmPick/releases/latest)
- [中文使用说明书](README.zh-CN.md)
- [默认快捷键](README.zh-CN.md#默认快捷键)
- [从源码构建](README.zh-CN.md#从源码构建)
- [第三方组件及许可](THIRD-PARTY.md)

单文件 EXE 可直接运行。使用便携 7z 时，完整解压后运行 `FilmPick.exe`。素材请放在本机 NTFS 固定磁盘的文件夹内。
