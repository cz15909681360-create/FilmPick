# FilmPick third-party notices

FilmPick launches [ExifTool 13.64 for Windows x64](https://sourceforge.net/projects/exiftool/files/exiftool-13.64_64.zip/download) as a separate metadata reader. The complete upstream runtime directory contains the ExifTool and Strawberry Perl license notices. [ExifTool source and license](https://exiftool.sourceforge.net/#license) · [Windows launcher, sources and licensing](https://oliverbetz.de/pages/Artikel/ExifTool-for-Windows)

FilmPick dynamically loads the separately replaceable x64 LGPL build of libmpv from its application directory.

- Build: [zhongfly/mpv-winbuild, 2026-11-10-d075ec2a28](https://github.com/zhongfly/mpv-winbuild/releases/tag/2026-11-10-d075ec2a28), asset `mpv-dev-lgpl-x86_64-20261110-git-d075ec2a28.7z`. Release asset SHA-256: `03e2a563417f0b335be03c044ce092977099c96498e6c7f60a44812b2c46d663`. Extracted `libmpv-2.dll` SHA-256: `214b93229e851764e7a3909ad9d4829a8b286d9434ad0878717466d6944dbb3d`.
- Corresponding build recipes and dependency sources: [build repository at the release commit](https://github.com/zhongfly/mpv-winbuild/tree/71a2766aafeb756974fe646e6b7084dd5c71287a), [libmpv at d075ec2a28](https://github.com/mpv-player/mpv/tree/d075ec2a28), [FFmpeg at 49a3b1f25](https://github.com/FFmpeg/FFmpeg/tree/49a3b1f25). The mpv LGPL configuration uses FFmpeg under LGPLv3. Applicable license texts are included in the portable distribution. See the recipe for statically included dependencies and their licenses.
- The application bundles Microsoft .NET 10 and the Windows Desktop runtime. The distribution includes the published runtime's license and third-party notices.
- RAW decoding uses the [MSYS2 UCRT64 build of LibRaw 0.22.3](https://packages.msys2.org/packages/mingw-w64-ucrt-x86_64-libraw), under LGPL 2.1. It uses libjpeg-turbo, Little CMS, zlib, winpthreads and GCC runtime libraries. The portable distribution includes the package licenses. Exact binary versions and SHA-256 checksums are in `package-raw.ps1`.
